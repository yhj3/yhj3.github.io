Projects

  • Brain Tumor Segmentation on Multi-Modal MRI: U-Net vs. TransUNet
    Yihang Jiao. Independent project, 2025. I built one training pipeline in which a U-Net, a configurable U-Net, and a TransUNet can be compared under identical data and training settings, so that a change in the score can be traced to a single deliberate change. Using it, I found that how the loss and the sampler are designed matters about as much as which backbone you choose, and that the transformer's advantage is concentrated on one kind of tumor region rather than spread evenly.
    Paper: yhj3.github.io/assets/papers/brats-unet-vs-transunet.pdf
    Write-up: yhj3.github.io/projects/brats.html
    Code available: https://github.com/yhj3/brats-unet-vs-transunet
    Weights available: https://huggingface.co/yihangj3/brats-transunet
  • VibeRepair+: Retrieval-Augmented Program Repair for Java and Python
    Yihang Jiao, Yingjia Gu, Shengyue Guo. CS Software Engineering for GenAI, 2026. I built a retriever framework for LLM program repair in which swapping in a new retrieval strategy takes one file, and then found that the evaluation everyone was using could not tell the retrievers apart — it was really asking whether a document can find itself, so every retriever scored perfectly. I designed a replacement protocol on real bugs, under which the ranking of the retrievers reverses and a simple lexical method beats the dense baseline.
    Paper: yhj3.github.io/assets/papers/viberepair-plus.pdf
    Write-up: yhj3.github.io/projects/viberepair.html
    Code available: https://github.com/yhj3/Vibe_Repair_Plus
  • LLM RAG Reranker with Pairwise Comparison and Citation Context
    Yexin Wu, Yihang Jiao. CS 598 Text Mining, 2024. Search over papers ranks them by what they say about themselves. We reranked candidates by letting a language model compare them two at a time, and made that affordable by treating its noisy judgments as a bandit problem so most comparisons can be skipped. We also built a corpus of citation contexts, so the reranker can see how a paper is actually used by others rather than only how it describes itself.
    Paper: yhj3.github.io/assets/papers/llm-rag-reranker.pdf
    Write-up: yhj3.github.io/projects/scilit-rag.html
  • What LLM Rewriting Costs an Adversarial Attack
    Yihang Jiao. Research assistant, FOCAL Lab, with Prof. Gagandeep Singh, 2024; revised 2026. Standard attacks on text classifiers swap words for synonyms; I had a language model rewrite whole sentences instead. Rewriting makes the attacks far more fluent, but it also destroys more than half of them — and how much it destroys turns out to be set by the prompt. The prompt that best preserves the attack on topic classification does so by instructing the model to change the topic, which produces a different input rather than an attack: a trap for any evaluation that reports flip rate without a paired semantic constraint. Revising this work meant auditing my own earlier version of it, in which the classifier had never been run on the rewrites at all. The corrected study, the audit, and the check that would have caught it are all in the paper.
    Paper (revised): yhj3.github.io/assets/papers/counterfactual-textattack-revised.pdf
    Paper (original 2024): yhj3.github.io/assets/papers/counterfactual-textattack.pdf
    Code available: https://github.com/yhj3/counterfactual-textattack

What I want to work on next

Evaluation protocols for machine learning on scientific data. Leave-one-out and random-split protocols are load-bearing in a lot of published results, and they overstate performance whenever the query and the gold answer share provenance — the retrievers in VibeRepair+ all scored a perfect recall@1 under a protocol that was really asking whether a document can find itself. The same shape shows up wherever the split does not hold out the thing the model is supposed to generalize over. What I would like to build is a checkable recipe rather than a new model: an external-query construction, a two-stage leak check, and a random-retrieval floor reported next to every headline number.

Also interested in: perturbational cell-state modeling. Predicting how a cell moves from a baseline state to a new one under a perturbation, with readouts that are heterogeneous — imaging, transcriptomics, perturbation metadata. I have not worked on this and have not thought it through in detail; I note it as something I find interesting and would like to learn. If you work on it, I would be glad to hear what I should be reading.
